# TableMate

Telegram bot for single-venue restaurant reservations: shows real-time availability, books/reschedules/cancels with confirmation codes and reminders; owner-only admin view.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
